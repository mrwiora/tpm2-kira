## Security Scanning

This repository uses advanced CodeQL security scanning to detect vulnerabilities in the codebase.

**Important:** The CodeQL workflow uses custom queries for enhanced security analysis. If you maintain this repository, you may need to disable the default CodeQL setup in GitHub settings. See [.github/CODEQL_SETUP.md](.github/CODEQL_SETUP.md) for configuration instructions.
